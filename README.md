# DataStructure

这是一个使用 C 语言学习数据结构与基础语法的练习项目。项目内容从 C 语言基础知识出发，逐步过渡到线性表、链表、栈、队列等常见数据结构的实现，并通过独立的 `.c` 文件展示不同知识点的代码示例。

仓库适合用于：

- 复习 C 语言数组、指针、结构体、字符串、函数和动态内存分配
- 理解线性表的顺序存储和链式存储
- 学习栈、队列等基础数据结构的核心操作
- 通过代码示例巩固数据结构课程中的基本概念
- 作为后续补充树、图、排序、查找等内容的练习仓库

## 一、项目整体结构

项目以 Visual Studio 工程为基础，同时每个知识点基本都拆分为独立的 `.c` 文件。多数文件中包含单独的 `main` 函数，便于单独运行和调试。

```text
DataStructure
├── klpoint.slnx                  Visual Studio 解决方案文件
├── klpoint.vcxproj               Visual Studio C/C++ 项目文件
├── array.c                       数组基础
├── pointer.c                     指针基础
├── struct.c                      结构体基础
├── function.c                    函数基础
├── string.c                      字符串基础
├── dynamic _memory_allocation.c  动态内存分配
├── recursion.c                   递归练习
├── LinearList.c                  顺序表与链表
├── LinkedList_Application.c      链表应用
├── stack.c                       栈
├── stack_Application.c           栈的应用
├── queue.c                       队列
├── tree.c                        树相关内容预留
└── supplement.c                  补充内容
```

## 二、学习顺序建议

建议按照下面的顺序阅读和运行代码，这样知识衔接会更自然。

### 1. C 语言基础

先阅读这些文件，理解后续数据结构代码中频繁使用的语法基础：

| 文件 | 建议学习内容 |
| --- | --- |
| `function.c` | 函数定义、函数调用、返回值、通过函数组织代码 |
| `array.c` | 数组定义、数组遍历、数组大小计算、数组地址 |
| `pointer.c` | 指针变量、取地址、解引用、指针传参、指针访问数组 |
| `struct.c` | 结构体定义、结构体变量、结构体指针、`typedef` |
| `string.c` | 字符数组、字符串复制、拼接、比较和长度计算 |
| `dynamic _memory_allocation.c` | `malloc`、`free`、动态数组、动态结构体 |

这些内容是后面实现链表、栈和队列的基础，尤其是指针、结构体和动态内存分配。

### 2. 递归基础

`recursion.c` 用两个简单问题对比循环和递归写法：

- 计算 `1` 到 `n` 的累加和
- 求斐波那契数列第 `n` 项

通过这个文件可以理解递归函数的基本结构：终止条件、递归调用和结果回溯。

### 3. 线性表

`LinearList.c` 是当前内容最完整的文件之一，包含顺序表和多种链表实现。

主要内容包括：

- 顺序表的初始化、插入、删除、查找和遍历
- 动态顺序表的内存申请与释放
- 单链表的初始化、头插法、尾插法、指定位置插入和删除
- 单向循环链表的初始化与遍历
- 双向链表的头插、尾插、指定位置插入、删除和释放

这个文件适合重点阅读，因为它集中体现了线性结构的两种核心存储方式：顺序存储和链式存储。

### 4. 链表应用

`LinkedList_Application.c` 用链表实现了一些典型应用题的基础框架。

当前已经包含：

- 链表初始化
- 头插法和尾插法
- 链表遍历
- 链表内存释放
- 使用快慢指针判断链表是否有环
- 查找链表环的入口节点

文件中还预留了多个适合继续补充的练习方向：

- 查找倒数第 `k` 个节点
- 查找链表中间节点
- 查找两个链表的相同后缀
- 链表反转
- 链表合并

这些题目都适合练习双指针、链表断链重连和边界条件处理。

### 5. 栈

`stack.c` 主要实现栈这种后进先出结构。

当前内容包括：

- 顺序栈的初始化
- 判断栈是否为空
- 入栈 `Push`
- 出栈 `Pop`
- 获取栈顶元素 `GetTop`
- 动态栈的初始化和释放
- 链式栈的初始化、入栈、出栈、取栈顶和清空

栈的核心特点是只允许在栈顶进行插入和删除，适合用于括号匹配、表达式求值、函数调用过程模拟等场景。

`stack_Application.c` 是栈应用题的预留文件，目前已经定义了基础结构和符号枚举，后续可以继续完善表达式求值、括号匹配等内容。

### 6. 队列

`queue.c` 主要实现队列这种先进先出结构。

当前内容包括：

- 顺序队列初始化
- 判断队列是否为空
- 入队 `Enqueue`
- 出队 `Dequeue`
- 获取队头元素 `GetFront`
- 队尾空间不足时的数据前移处理
- 动态队列的初始化与清理
- 循环队列的入队和出队
- 链式队列的初始化、入队、出队、取队头和清空

队列的核心特点是队尾插入、队头删除，适合用于任务调度、层序遍历、缓冲区等场景。

## 五、运行方式

### 方式一：使用 Visual Studio

项目包含 Visual Studio 工程文件，可以直接打开：

```text
klpoint.slnx
```

打开后可以根据需要选择某个 `.c` 文件进行调试。由于多个文件中都包含 `main` 函数，如果放在同一个工程中同时编译，可能会出现多个入口函数冲突的问题。调试时建议一次只启用一个包含 `main` 函数的文件。

### 方式二：单独编译某个 C 文件

也可以使用 GCC 单独编译某个文件，例如：

```bash
gcc LinearList.c -o LinearList
./LinearList
```

如果在 Windows PowerShell 中运行，生成的可执行文件通常可以这样执行：

```powershell
gcc LinearList.c -o LinearList.exe
.\LinearList.exe
```
