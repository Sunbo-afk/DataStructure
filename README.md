# DataStructure

这是一个使用 C 语言学习和实现数据结构基础知识的练习项目。仓库中包含线性表、链表、栈、队列、递归、指针、结构体、字符串、动态内存分配等内容，适合用于复习 C 语言基础语法以及理解常见数据结构的基本操作。

项目以单个 `.c` 文件为主要组织方式，每个文件围绕一个知识点或一种数据结构展开，并在 `main` 函数中给出简单的运行示例。

## 项目内容

| 文件 | 内容说明 |
| --- | --- |
| `array.c` | 数组的声明、遍历、大小计算、地址观察和求和示例 |
| `pointer.c` | 指针基础、值传递与地址传递、指针访问数组元素 |
| `struct.c` | 结构体定义、结构体函数返回、结构体指针和 `typedef` 用法 |
| `dynamic _memory_allocation.c` | 动态内存分配相关练习 |
| `function.c` | C 语言函数基础示例 |
| `string.c` | 字符串基础示例 |
| `recursion.c` | 递归与非递归写法对比，包括求和与斐波那契数列 |
| `LinearList.c` | 顺序表、动态顺序表、单链表、循环链表和双向链表的基础操作 |
| `LinkedList_Application.c` | 链表应用练习，包括环检测和环入口查找等 |
| `stack.c` | 顺序栈、动态栈和链式栈的基本实现 |
| `stack_Application.c` | 栈的应用练习，当前仍在完善中 |
| `queue.c` | 顺序队列、循环队列、动态队列和链式队列的基本实现 |
| `tree.c` | 树相关内容预留文件，当前仍在完善中 |
| `supplement.c` | 补充练习内容 |

## 已覆盖的数据结构

- 顺序表
- 单链表
- 单向循环链表
- 双向链表
- 顺序栈
- 链式栈
- 顺序队列
- 循环队列
- 链式队列

## 学习重点

- 理解数组、指针、结构体和动态内存分配之间的关系
- 掌握线性表的顺序存储和链式存储实现方式
- 熟悉栈和队列的核心操作，例如入栈、出栈、入队、出队和取队头元素
- 通过链表环检测等例子练习双指针思想
- 对比递归和循环两种解决问题的方式

## 运行方式

本项目包含 Visual Studio C/C++ 工程文件，可直接使用 Visual Studio 打开：

```text
klpoint.slnx
```

也可以单独编译某个 `.c` 文件进行测试，例如使用 GCC：

```bash
gcc LinearList.c -o LinearList
./LinearList
```

注意：仓库中的多个 `.c` 文件都包含独立的 `main` 函数，单独编译某个文件时更方便；如果一次性加入同一个工程编译，需要避免多个 `main` 函数同时参与链接。
